# Product Design Direction

## Product

This is an educational mathematics platform and administration system.

The interface should feel like a serious, modern engineering product,
not a marketing landing page and not a generic AI SaaS dashboard.

## Personality

- Precise
- Technical
- Calm
- Academic
- Functional
- Modern without being flashy

## Visual Direction

Prefer:

- strong information hierarchy
- restrained use of color
- clear typography
- compact but comfortable spacing
- purposeful borders
- meaningful visual grouping
- data-dense layouts where appropriate

Avoid:

- excessive gradients
- excessive rounded cards
- decorative glassmorphism
- unnecessary animations
- fake dashboard statistics
- generic AI SaaS aesthetics
- excessive badges
- excessive icons
- visual decoration without functional purpose

## Copy

Use concise Vietnamese UI copy.

Do not automatically append English translations.

Bad:
"Quản lý bài thi (Exam Management)"

Good:
"Quản lý bài thi"

Do not explain obvious terminology in parentheses.

Avoid marketing language such as:

- Unlock the power of...
- Seamlessly...
- Powerful...
- Effortlessly...
- Comprehensive...
- All-in-one...

UI text should sound like a real product team wrote it.
